# Codex直接利用を5分で始める

これはCodexを直接使う手順です。Discord製品の導入・受入は[音声repo](https://github.com/Kotodama-Project/discord-voice-template)で別に扱います。この手順に言霊専用のinstallやサーバー起動はありません。成果を作るrepoをCodexで開き、次のように頼みます。

```text
目的: このプロジェクトの初回起動手順を、初めて触る人が実行できる状態にする。
完了条件: READMEのコマンドで起動でき、必要な前提と確認方法が分かる。
制約: 既存データと無関係な変更を守る。新しい実行基盤は追加しない。
元資料: このrepoのREADME、既存の起動スクリプト、現在のIssue。
調査、必要な修正、検証、許可されたPR統合と結果確認まで進めて。
```

これは例です。仕事を架空に作らず、実際に終わらせたい一件を選びます。
途中で条件が変わったら、同じチャットに訂正を伝えます。成果の読戻しと、長く残す訂正の反映まで確認します。
