# Discord音声認識の修正 — 2026-09-06

基本モデルをfaster-whisperの **large-v3** に統一し、非公開の既存ASR環境へ配備した。Turboへの自動切替は行わない。短い静かな録音ではVADによる欠落を避け、長い音声はlarge-v3のまま既存VADを使う。

## 処理と出典

- 話者は個別Discordストリームと保存した話者表へ結び付け、語ごとの時刻・音響指標を保持する。音響指標は校正済みの正答率ではない。
- 同一音声の重複要求を同じsession内でまとめ、推論を直列化する。mixedの不一致部分は話者不明の参照候補とし、本文へ足さない。
- 一般語の無条件辞書置換を廃止する。local Qwenの文脈訂正は厳しく検証し、原文を変えず未確認候補として分離する。
- 旧n8nの「個別本文・混合参照・話者/時刻固定・不確かなら保持」を踏襲し、用語とプロンプトの出典revision/hashを結ぶ。停止済みCloudflare OSのlive SSOT接続は主張しない。
- 新fusedは元transcriptのSHAと結ぶ。取消・期限切れ・元ファイル変更の後の次の推論や保存を止める。権限確認は自動で行い、人へ毎回承認を求めない。
- raw全文、訂正候補、聞き直し対象を分ける。不確かな区間を要約の引用へ採用しない。古いimmutable版の検索も元のsource/quoteを検証する。

## 実測と残る受入

利用者が指定した約23秒の1人録音を、実際に配備したlarge-v3で再処理した。ASR要求は1回、71語の時刻を保持し、認識は約97秒だった。local Qwenの応答も受け取り、採用する訂正は0件、不確かな3区間を聞き直し対象とした。原音は変更していない。

人が聞き取った4つの比較箇所では、旧Turboは0、large-v3/VAD無効は3箇所を復元した。これは一つの録音の限定比較で、CERや一般的な正答率ではない。末尾の挨拶などの誤認識は残る。人の聞き取り内容を推論のヒントへ入れて採点したものではない。

コードの正負テスト、実録音の非公開診断、稼働bytesのreadbackを行った。新録音からDiscord返却までの全自動動作、多人会話、自然な3往復、900秒継続と長時間の遅延は別の受入。過去のDiscord GET/CDN403は再試行で突破せず、今回の診断は投稿を行っていない。ハルシネーションゼロや全Voice機能の完了は宣言しない。

公開資料に原音、発話本文、本人ID、private Taskの記録を含めない。[E14](acceptance/EVIDENCE.md#e14) は非公開の限定観測への参照であり、公開ファイルだけで実環境を再現できるという主張ではない。
