# 所有者の目的

2026-10-21の要求により、Company AGI/Company OSを独自開発する旧方針を終了します。
現行の決定は[方針の決定](DECISIONS.md)です。このパスは既存リンクから新方針へ辿るために残します。

残す目的は、会話で示した原意・制約・訂正を保ち、必要な仕事を進め、成果を検証して次の仕事に活かすことです。
OpenAIの製品と既存のGitHub記録で満たせることは、それらに任せます。

以前のCompany OS、causal ledger、OKF、agent hierarchy、専用GUI、provider-neutral基盤は、現在の必須実装ではありません。
旧要求と設計の全文は[旧版の履歴](https://github.com/Kotodama-Project/Kotodama-project/blob/50ca4d2cf0c0e0e64cba17d8f3bc34fba2634b5b/docs/OWNER-INTENT-COMPANY-AGI.md)にあります。歴史の参照を、新しい実装指示として扱わないでください。
