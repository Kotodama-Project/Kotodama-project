# Support

This repository is an incomplete public preview, not a supported Public Beta.

- Use GitHub Issues for reproducible bugs, documentation problems, and bounded
  feature proposals that contain no sensitive information.
- Use the private process in `SECURITY.md` for vulnerabilities.
- Do not post credentials, private infrastructure details, participant data,
  audio, transcripts, or private source bodies.
- Public Discord invitations, a public Voice Bot, production deployment, and
  operational service-level commitments are not currently offered.

When opening an issue, include the revision, operating system, Python version,
the smallest safe reproduction, and the observed result. State clearly when a
check was not run.
