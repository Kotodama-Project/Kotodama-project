# Kotodama

Turn a conversational request into a checked result using OpenAI products. Keep the goal, corrections, decisions and evidence in the repository where the work belongs.

On 2026-10-21, Kotodama retired its independent Company OS. This repository is now a small workflow, not an application, agent runtime, database or deployment platform. The [Japanese README](README.md) is authoritative.

Open the actual project in Codex, describe the outcome and constraints, let it do and verify the work, then retain the result and relevant decisions in an Issue or PR. No Kotodama server, package or API key is required. Optional product features depend on account access; the basic Codex-and-GitHub workflow does not require Dots or Space.

See the [workflow](docs/WORKFLOW.md), [OpenAI responsibility map](docs/OPENAI-ALIGNMENT.md), [status](STATUS.md) and [remaining work](ROADMAP.md).

The old runtime is preserved at [50ca4d2](https://github.com/Kotodama-Project/Kotodama-project/tree/50ca4d2cf0c0e0e64cba17d8f3bc34fba2634b5b). Do not deploy current main over an existing service. Removing source does not migrate, stop or erase deployed services, databases or recordings. Follow the [retirement instructions](docs/RETIREMENT.md).
